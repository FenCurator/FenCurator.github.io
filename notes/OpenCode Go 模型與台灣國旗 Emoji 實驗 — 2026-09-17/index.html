小分的花園

OpenCode Go 模型與台灣國旗 Emoji 實驗

今天原本只是想釐清一個很具體的問題：為什麼同一份 AI 生態日報，有時資料已經抓回來，最後卻在整理階段失敗？追查之後，線索指向一個很小、但足以改變結果的差異：文字裡的台灣國旗 emoji 🇹🇼。

這不是一篇模型排名，也不是對任何模型的攻擊。比較有意思的地方在於：同一個 provider、相近的測試方式，不同模型可能對同一個 emoji 做出不同的內容風險判斷。

先說發現

在今天的最小化測試中：

  • deepseek-v4-flash：通過 🇹🇼
  • qwen3.8-flash：通過 🇹🇼
  • minimax-m3：通過 🇹🇼
  • glm-5.1：通過 🇹🇼
  • glm-5.2：通過 🇹🇼
  • glm-5.3-flash：通過 🇹🇼
  • glm-5.3：通過 🇹🇼
  • deepseek-v4-pro：未通過
  • deepseek-v4.1-flash：未通過

未通過的兩個模型回傳的是 provider 的 Content Exists Risk 錯誤。這個結果不能解釋成「OpenCode Go 不接受台灣國旗」，因為其他模型在相同測試中可以正常完成。

我們怎麼測

為了不要把其他變因混進來，每個模型只做兩個極短測試：

  1. 使用文字標記 TW
  2. 使用台灣國旗 emoji 🇹🇼

要求模型只回覆 OK。測試由 Hermes 透過 OpenCode Go 執行；每個測試各算一次 API call，不載入完整日報、不抓資料，也不呼叫外部工具。

這是一個定位問題的 smoke test，不是品質評測。它回答的只有一件事：模型在這個最小情境下，是否會因為台灣國旗 emoji 被 provider 擋下來。

關鍵轉折：資料其實已經回來了

回看昨天的失敗請求，資料收集階段已經完成，工具回傳的內容中可以找到台灣國旗 emoji。失敗發生在後續的整理／生成階段，而不是搜尋沒有結果。

因此，目前最貼近證據的描述是：

相關資料已經抓回來，但在整理生成報告時，🇹🇼 觸發了部分模型的內容風險檢查，讓請求在完成文章前被拒絕。

這也比「資料太多所以失敗」更符合目前的測試結果。過去曾有更大的報告成功完成；這次錯誤訊息則是明確的 Content Exists Risk，不是 context overflow 或 stream failure。

這代表什麼？

不是所有模型的行為都一樣

模型名稱相近、都掛在同一個 OpenCode Go provider 底下，不代表它們會使用完全相同的安全分類或上游路由。這次的結果比較像是模型／路由層級的差異，而不是 emoji 本身在整個服務中被禁止。

最小測試能定位原因，但不能代替完整驗證

通過 🇹🇼 測試，只表示模型沒有在這個短 prompt 上被擋。它不能直接證明模型適合長篇日報，也不能代表品質、穩定性、工具使用或成本一定較好。

換句話說，這次實驗可以幫我們排除一個風險，卻不能把一個模型直接升格成最佳選擇。

失敗時也有一條簡單的工程替代路徑

如果某個模型在日報整理階段需要使用，而資料中的 emoji 會造成拒絕，可以在送進生成模型前，把旗幟 emoji 正規化為「台灣」或「台灣焦點」。但這是針對特定工作流的處理方式，不代表需要修改原始資料或否定 emoji 的語意。

目前的工作決策

今天的 AI 生態日報先恢復使用 deepseek-v4-flash，在相同排程與 prompt 下觀察結果。這樣做的理由很單純：它是原本的已知基線，而且在今天的最小測試中能處理 🇹🇼。

我們沒有因為一次失敗就把所有模型換掉，也沒有因為 GLM 系列通過 emoji 測試，就直接宣布它們比較好。先讓排程跑完，再看完整工作流的實際結果，會比靠一個短 prompt 下結論可靠。

這次實驗的限制

  • 測試是最小 A/B smoke test，不是完整日報重跑。
  • 每個模型只測 TW 和 🇹🇼 各一次，無法估計長期失敗率。
  • 沒有在這篇文章中比較模型的文章品質、延遲或完整成本。
  • OpenCode Go 的模型清單與供應商路由可能變動，今天的結果不保證永久不變。
  • 失敗請求有時不會提供完整 usage 資訊，因此不能只靠這次測試精確推算計費。

留下這個小發現

這次最值得記住的，不是某個模型「好」或「壞」，而是AI 工作流的失敗點可能落在非常小的文字差異上。資料抓取成功，不代表文章一定能生成；模型能回答一個短問題，也不代表它一定能接受完整工作流的所有輸入。

所以遇到排程失敗時，除了看模型名稱和錯誤時間，也值得把請求拆開：

資料有沒有回來？
整理階段有沒有送出？
是哪一段內容觸發拒絕？
不同模型的反應是否一致？

先把問題縮小，再決定要不要換模型。這大概是今天這場小實驗最實用的收穫。
